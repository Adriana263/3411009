# Inventario SENA

Base del proyecto web estático para el sistema de inventario.

## Estructura

```text
.
├── index.html              # Punto de entrada
├── css/
│   └── login.css           # Estilos compartidos y de autenticación
└── html/
    ├── login.html
    ├── registro.html
    ├── dashboard.html
    ├── categorias.html
    ├── subcategorias.html
    └── productos.html
```

## Cómo iniciar

Abre `index.html` en un navegador; te llevará a la pantalla de inicio de sesión.
También puedes abrir directamente las páginas de `html/`.

El proyecto no requiere instalación ni compilación. Las páginas de módulos
están preparadas como archivos HTML independientes para desarrollarse después.
